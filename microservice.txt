1.consumer application should be enabled with Feign Client functionality.

2.Add an annotation called @EnableFeignClient in main Spring Boot Application at class level

3.Create Feign Client interface:

    which Micro Service API ,we are calling ,for that specific MS ,we have to create an individual Feign client Interface.
    

   -> When we added @FeignClient annotation on interface ,that will be consider as Feign Client

      @FeignClient
      public interface PaymentMicroServiceFeignClient{


     }

4.Now please provide producer micro service ID inside @FeignClient as value

      @FeignClient(value="payment-service")
      public interface PaymentMicroServiceFeignClient{


     }
 

5.Create an Abstract method inside interface ,that method return type should be similar response of API call.

     -> if that api is having Request Body ,define compatible java class as a method argument

     ->Define an endpoint URl of API in the formate of Request mapping Annotation.

         @FeignClient(value="payment-service")
      public interface PaymentMicroServiceFeignClient{

              @GetMapping("/payment/option")
              reponseType getPaymentOption();
                  
             
     }
 
6. Now Use the Reference variable of feign client interface to call the method ,where it is required in the application ar per need 

    ->Inject /Autowired the feign client in service class and call the resptective method where it is need.
             
              @Autowired
              PaymentMicroServiceFeignClient feignClient;

             use feignClient object to call the method of this interface as per nedd.
